# Heart Disease Detection

A machine learning project for cardiovascular risk prediction
using Random Forest, SVM, and weighted probability fusion.

## Planned Features
- Manual patient health form
- Medical report upload and value confirmation
- UCI Heart Disease dataset
- Random Forest and SVM model comparison
- Weighted probability fusion
- Streamlit user interface

## Tech Stack
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit

## Disclaimer
This project is for research and educational purposes.
Predictions are not a substitute for professional medical advice.
